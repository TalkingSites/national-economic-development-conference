# National Economic Development Conference

Website for the National Economic Development Conference, presented by Economic
Development Australia.

Live site: [edaconference.com.au](https://edaconference.com.au/)

## Built with SpaceClub

This site uses the [SpaceClub](https://github.com/talkingsites/spaceclub-template)
template, an Eleventy based static site template. Documentation for how it works
is in the [SpaceClub wiki](https://spaceclubwiki.talkingsites.org).

    npm install
    npm start      # local dev server at http://localhost:4173
    npm run build  # writes _site/
